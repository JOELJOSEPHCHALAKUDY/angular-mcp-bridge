Use `list_projects` to open the project browser and `get_project` to query a project without opening another view. Use `open_lab` to explore Angular signals, resources, view-defined tools and the Angular modal.

Views feature-detect host capabilities. Respect missing capabilities instead of claiming an action succeeded. The shared note is demonstration data held in the server process; it is not durable storage.
